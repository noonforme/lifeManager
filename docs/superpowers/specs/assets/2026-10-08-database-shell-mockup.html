What changed

  • Version 4: no keyboard shortcuts or arrow-key movement (the keyboard only enters values in an editor); no Properties key and no "Open as dialog". The only windows left are confirmations.
  • Removed: the desk tabs (Today, Overview) and the saved views in the tree.
  • Real look: EraSans at 11px, gradients sampled from the real-font goldens (menu, toolbar, filter strip, column headers), XP scrollbars, dotted tree lines with ⊞/⊟ boxes, the app's painted icons, and Back / Forward / Add orbs.
  • Filled the left column: a Details box under the tree shows the employment's context (agreement, rate, schedule, open period, last payslip), so no space is left empty.
  • Property column follows VB's Properties window: an object box at the top, Categorized / A↓Z, the value being edited shown as a time box with spin arrows, changed values in bold with the old value next to them, read-only derived values in grey, "Belongs to" links, and a description pane.
  • Real numbers: EUR 18.40/h with a 50% night premium, a 3 days / 3 nights rotation, and the 24–25 October night running 13 hours because the clocks go back, as in the existing goldens.
